# Youtu 2B vs Qwen3.5 2B vs Qwen3 1.7B

测试日期：2026-11-08

## 固定条件

- GPU：NVIDIA GeForce RTX 2050 4GB
- 后端：llama.cpp CUDA，build b12013
- Youtu：`Youtu-LLM-2B.Q4_K_M.gguf`
- Qwen3.5：`Qwen3.5-2B-Q4_K_M.gguf`
- Qwen3：`qwen3-1.7b-4bit.gguf`
- GPU 全量卸载：`-ngl 99`
- 上下文：`-c 8192`
- 单并发：`-np 1`
- 基线采样：`temperature=0.1, top_p=0.95, top_k=50, repeat_penalty=1.1`
- 关闭 reasoning：`-rea off --reasoning-budget 0`

## 测试集

复用 `../lfm3_vs_qwen3/benchmark.py`：

- 中文/英文精确输出
- 中文/英文数学
- 中文/英文 JSON 提取
- 中文/英文告警分类
- 中文/英文工具选择
- 中文/英文工具链
- 路径长度工具
- 较长上下文检索
- 网络概念问答

每个模型运行 15 个用例 × 3 轮，共 45 次。

## 总体结果

| 指标 | Youtu 2B | Qwen3.5 2B | Qwen3 1.7B |
|---|---:|---:|---:|
| 任务正确率 | 88.9% | 100.0% | 100.0% |
| 格式严格遵循率 | 93.3% | 93.3% | 86.7% |
| 中位耗时 | 0.618s | 1.323s | 1.130s |
| P95 耗时 | 1.193s | 2.784s | 2.041s |
| 输出 token 中位数 | 26 | 32 | 27 |
| 截断次数 | 0 | 0 | 0 |

Youtu 2B 的 decode 速度明显更高，短输出和工具调用场景约
`41–45 token/s`，因此在中位和 P95 延迟上都明显领先。

## 失败样本

Youtu 2B 的 5 次失败来自两类任务：

1. 英文 JSON 提取有 2/3 轮把设备名输出为 `"Device R2"`，
   而期望值为 `"R2"`。
2. 长上下文暗号提取 3/3 轮只返回 `42`，遗漏了完整代码 `BLUE-42`。

其他中文/英文指令、数学、分类、工具选择、工具链和网络问答均通过。

## Youtu 官方采样参数复测

模型元数据推荐：

```text
temperature=1.0
top_p=0.95
top_k=20
```

本次不额外设置 repeat penalty。

### 两种采样参数对比

| 指标 | 固定基线 | Youtu 官方参数 |
|---|---:|---:|
| 任务正确率 | 88.9% | 86.7% |
| 严格格式遵循率 | 93.3% | 97.8% |
| 中位耗时 | 0.618s | 0.566s |
| P95 耗时 | 1.193s | 0.959s |
| 输出 token 中位数 | 26 | 22 |
| 截断次数 | 0 | 0 |

官方参数的变化：

- 中位耗时降低约 8.4%；
- P95 降低约 19.6%；
- 输出 token 中位数从 26 降到 22；
- 严格格式遵循率从 93.3% 提升到 97.8%；
- 英文 JSON 从 1/3 正确变为 0/3 正确；
- 长上下文仍然是 0/3 正确，三轮都只输出 `42`；
- 总体正确率下降 2.2 个百分点。

官方参数下实际 Agent 三轮：

| 轮次 | BFS | 路径智能体 | 端到端 |
|---|---:|---:|---:|
| 1 | 1.187s | 1.442s | 2.682s |
| 2 | 1.052s | 0.778s | 1.877s |
| 3 | 0.985s | 0.773s | 1.802s |

预热后中位约 `1.88s`，与基线 `1.91s` 基本一致。

## 结论

没有单一模型在所有维度胜出：

- **当前固定 BFS/路径 Agent 的延迟优先场景：Youtu 2B 最好。**
  它能把预热后的完整链路稳定压到约 1.9 秒，并且该路径结果正确。
- **通用正确性和稳定性优先：Qwen3 1.7B / Qwen3.5 2B 更好。**
  两者在 45 次测试中全部正确，而 Youtu 在英文 JSON 和长上下文上失败。
- **严格格式优先：Qwen3.5 和 Youtu 均为 93.3%，高于 Qwen3 的 86.7%。**
  Youtu 使用官方采样参数后可以进一步提升到 97.8%。

因此当前网络运维 Agent 可以选择两级策略：

- 简单路径、分类、短回答走 Youtu 2B，利用其低延迟。
- JSON 抽取、长上下文检索和需要高正确率的任务走 Qwen3 1.7B 或 Qwen3.5 2B。
