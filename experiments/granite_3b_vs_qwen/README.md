# Granite 4.2 3B 对比实验

测试日期：2026-11-08

## 模型

- Granite：`granite-4.2-3b-Q4_K_M.gguf`
- 对比模型：Qwen3.5 2B、Qwen3 1.7B、Youtu 2B、MiniCPM5 2B

## 固定条件

- GPU：NVIDIA GeForce RTX 2050 4GB
- 后端：llama.cpp CUDA，build b12013
- GPU 全量卸载：`-ngl 99`
- 上下文：`-c 8192`
- 单并发：`-np 1`
- 关闭 reasoning：`-rea off --reasoning-budget 0`
- 统一基线采样：`temperature=0.1, top_p=0.95, top_k=50, repeat_penalty=1.1`
- Granite 推荐采样：`temperature=1.0, top_p=0.95, top_k=40, repeat_penalty=1.0`

## 测试集

复用 `../lfm3_vs_qwen3/benchmark.py`：

- 中文/英文精确输出
- 中文/英文数学
- 中文/英文 JSON 提取
- 中文/英文告警分类
- 中文/英文工具选择
- 中文/英文工具链
- 路径长度工具
- 较长上下文检索
- 网络概念问答

15 类用例 × 3 轮 = 45 次。

因此默认保留统一基线。

## 与其它模型对比

| 指标 | Granite 3B | Qwen3.5 2B | Qwen3 1.7B | Youtu 官方 | MiniCPM5 官方 |
|---|---:|---:|---:|---:|---:|
| 正确率 | **100.0%** | 100.0% | 100.0% | 86.7% | 80.0% |
| 严格格式遵循率 | **100.0%** | 93.3% | 86.7% | 97.8% | 88.9% |
| 中位耗时 | 0.970s | 1.323s | 1.130s | **0.566s** | 0.523s |
| P95 耗时 | 3.098s | 2.784s | 2.041s | **0.959s** | 0.967s |
| 输出 token 中位数 | 32 | 32 | 27 | **22** | 23 |

Granite 的优势：

- 在当前测试集中正确率和严格格式遵循率都是 100%；
- 中文 JSON、分类、路径长度和长上下文全部通过；
- 中文/英文工具链都严格按纯结果输出。

Granite 的劣势：

- 工具调用输出 token 更多；
- 长回答类任务的生成时间波动较大；
- 网络概念问答中位数约 4.54s，P95 主要受该任务影响。

## 结论

- 要求高正确率和严格输出协议：Granite 3B 是当前最强候选，测试中为
  45/45 正确且 45/45 严格格式通过。
- 要求低延迟：Granite 不适合当前四次 LLM 调用的 Agent 链路，明显慢于
  Youtu、MiniCPM5 和 Qwen3。
- 均衡选择：Qwen3 1.7B 仍更适合作为默认模型。
- 最合理的部署方式仍是按任务路由：快速路径使用 Youtu/MiniCPM5，
  严格 JSON 和格式任务使用 Granite，普通高质量任务使用 Qwen3。
